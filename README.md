# Exercicio-pizza
## Exercício para praticar e pegar a pratica de HTML simples e introdutório 

**Site para Amantes de Pizza**
Página HTML simples desenvolvida como exercício, apresentando uma pizzaria fictícia com menu de navegação e textos introdutórios.

*Descrição:*
Este exercício tem como objetivo praticar estrutura básica de HTML: títulos, parágrafos, imagem, linha divisória, links e listas.

*A página contém:*

Imagem de destaque: uma imagem ilustrativa no topo da página, com largura fixa de 250px.
Título e subtítulo: apresentação do site ("Site para amantes de pizza") e uma linha horizontal (<hr>) separando o cabeçalho do conteúdo.
Seção 1: título de destaque seguido da "Sessão de pizzas".
Menu de navegação: lista ordenada (<ol>) com links para Home, Cardápio, Áreas de Entrega e SAC.
Textos finais: dois parágrafos falando sobre pizzas, com a palavra "pizzas" destacada em negrito usando <strong>.

**Tecnologias utilizadas:**
 HTML5
